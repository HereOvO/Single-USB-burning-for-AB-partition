# STM32 Bootloader 上位机固件升级脚本

## 功能说明
此脚本用于监控版本文件变化，并自动通过USB串口将固件升级到STM32单片机。

## 依赖库安装
```bash
pip install pyserial watchdog
```

## 使用方法

### 1. 硬件准备
- 确保STM32开发板通过USB连接到电脑
- 确保设备处于Bootloader模式
- 确认USB CDC虚拟串口被识别（如COM23）

### 2. 文件准备
- 确保 `Test\version.txt` 文件存在，包含当前版本号
- 确保 `Test\My_APP.bin` 固件文件存在

### 3. 运行脚本
```bash
python final_upload_script.py
```

### 4. 触发升级
修改 `Test\version.txt` 文件中的版本号，脚本会自动检测变化并开始固件升级。

## 协议说明
- 启动命令格式: `[0xA5][0x5A][0x06][0x00][固件大小(4字节LE)]`
- 固件大小以小端序4字节格式发送
- 发送启动命令后等待ACK响应
- 每个512字节数据包发送后等待ACK响应
- 脚本会按通信格式打印下位机发回的信息
- 如果ACK响应超时，脚本会停止程序
- 如果收到错误响应，脚本会终止升级过程
- 仅使用COM23端口与STM32通信

## 故障排除
如果遇到串口连接问题，请检查：
1. STM32是否正确连接到电脑
2. 是否处于Bootloader模式
3. USB驱动是否正确安装
4. 端口是否被其他程序占用
