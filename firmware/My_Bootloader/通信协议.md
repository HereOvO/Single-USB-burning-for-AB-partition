



# Bootloader程序,以及APP程序中与Bootloader相关的部分的通信协议都基于以下结构体和其实例:

## 通信结构体

```c
//与上位机通信的结构体
typedef struct {
    uint8_t magic_head;//魔数
    uint8_t magic_end;//结束魔数
    uint8_t  cmd;//指令
    uint8_t  BootloaderState;//运行状态
    uint8_t* data;//以\0结尾的其它信息
} BootloaderPacket_t;
```

`BootloaderPacket_t`类型是下位机和上位机之间通信的标准模式,下位机通过函数`Send_BootloaderPacket`将这个类型的结构体发送给上位机,在**USB中断中**解析这个类型的结构体

其中各个字段的定义是下面几个结构体的字段:

通过**结构体的标准实例**定义了`Send_BootloaderPacket`中各个字段的有限类型

## CMD类型

```c
//命令类型
typedef struct 
{
   uint8_t Cmd_Which_State;
   uint8_t Cmd_Invalid;  
   uint8_t Cmd_ACK;
   uint8_t Cmd_NACK;
   uint8_t Cmd_Update_State;
   uint8_t Cmd_Jump_To_A;  
   uint8_t Cmd_CopyB_To_A_Jump_To_A;
   uint8_t Cmd_Updata_A;
   AllERRORs_t* AllERRORs;
}AllCmds_t;

//错误类型
typedef struct 
{
   uint8_t ERROR_Flash_Erasure;
   uint8_t ERROR_Flash_Download;  
   uint8_t ERROR_Copy_B_To_A;
   uint8_t ERROR_Copy_A_To_B;
   uint8_t ERROR_Jump;
}AllERRORs_t;

//标准状态定义
AllERRORs_t AllERRORs = {0x01, 0x02, 0x03, 0x04, 0x05}; // 初始化错误码
AllCmds_t AllCMDs = {0, 1, 2, 3, 4, 5, 6, 7, &AllERRORs};
```

这两个结构体定义了`Send_BootloaderPacket`中`cmd`字段的取值

| 命令                                                    | 说明                                                         | 备注                                                         |
| ------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| Cmd_Which_State                                         | 上位机询问下位机状态                                         | 上位机发送给下位机,下位机回复状态                            |
| Cmd_Invalid                                             | cmd的默认类型                                                | 无意义                                                       |
| Cmd_ACK & Cmd_NACK                                      | 应答位 & 非应答位                                            | 在传输bin文件包的开始和过程中,每个包之间上位机需要等待下位机的应答 |
| Cmd_Update_State                                        | 更新状态                                                     | 只能下位机发送,用来提醒上位机更新下位机的状态,以实现状态控制,当上位机接受到这个命令的时候,需要根据下位机发送的`BootloaderPacket_t`中的`BootloaderState`字段修改记录的状态 |
| Cmd_Jump_To_A & Cmd_CopyB_To_A_Jump_To_A & Cmd_Updata_A | 上位机发送给下位机的开始模式的命令 & 应用程序中跳转回Bootloader程序的命令 | 决定了Bootloader的运行模式 & 如果在应用程序中接到Cmd_Updata_A,会从应用程序中调回Bootloader |
| ERROR_Flash_Erasure & ERROR_Flash_Download              | 内存擦除错误 & 写入flash错误                                 | 下位机发送给上位机                                           |
| ERROR_Copy_B_To_A & ERROR_Copy_A_To_B                   | \                                                            | 下位机发送给上位机                                           |
| ERROR_Jump                                              | 跳转发生错误                                                 | 下位机发送给上位机                                           |

## 运行状态结构体

```c

//Bootloader开始模式的状态机
typedef struct 
{
   uint8_t Start_Invalid;  
   uint8_t Start_Dirrectly_Jump_To_A;
   uint8_t Start_CopyB_To_A_Jump_To_A;
   uint8_t Start_Updata_A;
}AllBootloaderStartModes_t;

//Bootloader运行状态的状态机
typedef struct 
{
   uint8_t Run_Invalid;  //无效,不改变状态
   uint8_t Run_Waiting_Cmd; //等待命令
   uint8_t Run_Receiving_Bin;//接收bin
   uint8_t Run_Flash_Erasure;  //擦除flash
   uint8_t Run_Flash_Write;  //写入flash
   uint8_t Run_Copy_B_To_A;  //复制B到A
   uint8_t Run_Prepare_To_Jump_To_A;  //准备跳转到A
   uint8_t Run_Prepare_To_Jump_To_B;  //准备跳转到B

}AllBootloaderRunStates_t;

//储存实际状态的结构体
typedef struct 
{
   uint8_t StartMode,RunState;
}BootloaderState_t;



//标准状态定义
AllBootloaderStartModes_t AllBootloaderStartModes = {0, 1, 2, 3};//Bootloader开始模式的状态机
AllBootloaderRunStates_t AllBootloaderRunStates = {0, 1, 2, 3, 4, 5, 6, 7};//Bootloader运行状态的状态机

//实际状态结构体
BootloaderState_t BootloaderState;
```

使用`BootloaderState`中的`StartMode`和`RunState`来实现**状态机**

前者决定了Bootloader**以什么模式运行**

| 取值                       | 说明                        | 备注                                                         |
| -------------------------- | --------------------------- | ------------------------------------------------------------ |
| Start_Invalid              | Bootloader开始的默认状态    |                                                              |
| Start_Dirrectly_Jump_To_A  | 直接从Bootloader跳转到A     | 程序上电默认进入Bootloader,需要上位机发送这个命令或者超时进入A程序 |
| Start_CopyB_To_A_Jump_To_A | 使用备份程序覆盖A程序并跳转 |                                                              |
| Start_Updata_A             | 升级A程序                   | 之后单片机会根据上位机发来的与`Cmd_Updata_A`同一个`BootloaderPacket_t`类型的信息中的`data`字段中解析出来的uint32_t类型的bin文件的大小先擦除flash[^ 注],然后进入bin文件接收模式 |

[^ 注]: 这时的data字段应只有一个uint32_t的size数据,小端序存放
